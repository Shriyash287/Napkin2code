Why Napkin2Code?

Turning a paper wireframe into an interactive interface usually means rebuilding everything by hand. Napkin2Code makes that first translation quicker: photograph a sketch, review the layout, and generate an editable page.

Built for the hackathon

A project for the MLH Open Source AI Hackathon — Hacktoberfest Hack Day, Pune. The application code is MIT licensed. It uses the open-weight Gemma 4 family through Google's hosted Gemini API.

Where your data goes

Projects are saved in your browser. When you analyze, generate, or edit, the local Python server sends the necessary image, specification, code, or instructions to Google. The API key remains on the server. Camera video is not streamed to Google; only a selected captured frame is sent for analysis.

This version needs internet access and a Gemini API key. Google's API terms, data handling, quotas, and any applicable charges govern AI requests.

Open model, open process

The exact model name is discovered from your account and shown in AI setup. See the Gemma 4 model card and Gemma API documentation.
