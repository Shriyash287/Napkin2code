A SMALL GUIDE TO BIG IDEAS

From sketch to something you can click.

Your first project, one step at a time.

1. Connect your AI

Complete AI setup with a server-side Gemini API key. Napkin2Code discovers an available Gemma 4 instruction-tuned model and verifies image support.

2. Capture the idea

Open Scan sketch. Enable your webcam or upload a JPG, PNG, or WebP file up to 10 MB. “Use sample sketch” loads a simple login form. Add a project name and optional instructions.

3. Review the interpretation

Click Analyze sketch. Check the detected layout in Visual outline or edit the JSON directly. Keep the title and elements array, then choose Generate website.

4. Try it and refine it

The builder includes an interactive preview, the original specification, and editable HTML. Apply a typed instruction, upload handwritten changes, or capture new annotations. Undo restores the preceding version.

5. Take the code with you

Copy the HTML or download one file. Open it in a browser to try the prototype. Project backups are available in Settings.

If something goes wrong

  • Camera blocked: allow camera access for localhost or use image upload.
  • Missing key: add GEMINI_API_KEY to .env, then test the connection.
  • No supported model: check model access in your Google account. The app does not switch to another model family.
  • Quota error: check your API quota and wait before retrying.
  • Unclear output: improve lighting, write larger labels, and simplify the sketch.
  • Storage full: export HTML and a project backup before clearing browser data.

What this prototype does

Generates frontend prototypes. Real accounts, payments, databases, and production deployment need separate implementation. AI output can contain mistakes. Review exported code before publishing it. The preview runs separately from the workspace and blocks network requests.
