How it works

Four steps from paper to production

Everything runs locally on your machine. No cloud subscriptions, no API keys, and no risk of leaking early-stage IP.

Need to swap a CTA, insert a customer review row, or adjust column span? Cross it out or draw an arrow on your notebook. Napkin2Code computes a semantic AST diff and patches the code without re-generating from scratch.

terminal Two-Minute Quickstart

Get up and running with Ollama

Napkin2Code plugs directly into your local Ollama installation. Once the vision model weights are downloaded to your disk, you are completely offline-ready. Generation speed scales directly with your GPU hardware.

bolt Metal & CUDA Ready
wifi_off 100% Offline Capable
lock_reset Zero Cloud Reliance
bash ~ local setup OLLAMA_HOST=127.0.0.1
# 1. Install Ollama engine
curl -fsSL https://ollama.ai/install.sh | sh
# 2. Pull vision & coding models
ollama run llama3.2-vision
# 3. Launch Napkin2Code
npx napkin2code dev
